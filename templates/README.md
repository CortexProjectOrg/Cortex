# Templates for extending the notebook

[Study index](../README.md) · [Personal path](../PERSONAL_PATH.md) · [Notes](../notes/README.md)

| Template | Use it for |
|---|---|
| [SESSION.md](SESSION.md) | One new study session with a question, prerequisites, selected sources, theory, and an experiment |
| [NOTE.md](NOTE.md) | A reusable explanation of one concept or a dated reflection |
| [EXPERIMENT.md](EXPERIMENT.md) | A prediction, reproducible procedure, result, and conclusion |

Copy a template to a descriptive file or new numbered session folder. Fill its blanks, then add navigation links to its index, preceding session, and notes as appropriate. The template bodies avoid placeholder file links so an unfilled template does not create broken navigation.

A new session can use the same four-hour pattern as the first month. If you deliberately change the theory/practice balance or time budget, write down the choice. Keep the essential task small enough that the extension really is optional.

Add new source entries with the selection and stopping point you intend to use, rather than adding a long list to read in full.
